# Void Runner

An 8-bit side-scrolling space shooter that runs in the browser — a single `index.html`, no build step, no dependencies.

**Play:** https://denis-semionov.github.io/void-runner/

## How to play

- **Thrust:** Space / ↑ / W, or click / tap. Hold to glide. Auto-fire is always on.
- **Pause:** P or Esc (or the pause button, top-right).
- Fly through the gaps in the towers, shoot the aliens before they stack up, and grab power-up cards.
- Beat the Dreadnought boss to unlock new ships in the **Hangar** (1, 3, 10 and 25 defeats).

## Features

- Five levels, each with its own procedurally drawn 8-bit solar system backdrop
- Visual-novel style intro cutscene with a shattering-monitor transition into the game
- Five unlockable ships with small perks
- Power-ups: Rapid, Double, Shield, Slow, Magnet, Score x2, +Life — cards ricochet off structures
- Progress (best score, boss defeats, equipped ship) saved in the browser's localStorage

## Run locally

Open `index.html` in any modern browser.
